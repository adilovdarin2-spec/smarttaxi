# SmartTaxi — комплект для проверки заказчиком, 9 сентября 2026

Статус: локальные web/Android сценарии поездки проверены. Это **не разрешение
на публичный запуск** и не заявление, что каждый экран/устройство идеален.
Production, мерчант и юридические действия не выполнялись.

## Что исправлено в этом сеансе

- На физическом Android подтверждён и исправлен уход конца маршрута за экран
  при сворачивании панели тарифа: камера сначала выравнивается, затем вписывает
  весь маршрут с отступами измеренной панели. Устаревшие асинхронные запросы
  камеры не применяются. Геометрия дорог и выбор маршрута не подменялись.
- Машина на карте пассажира уменьшена с 0.12/0.10 до 0.05 и центрирована на
  координате; физически проверен масштаб относительно улицы.
- При поиске водителя отмена доступна сразу. В назначенной поездке контакты,
  модель/номер машины и стоимость находятся перед второстепенными сведениями.
  Полные адреса доступны в раскрываемом блоке, без обрезанного номера дома.
- Добавлены переводы заголовка деталей на RU/KK/UZ/ZH и исправлена русская
  формулировка количества ближайших водителей.
- В финальном исходном коде поздний ответ стартовой геолокации не меняет
  адрес восстановленной поездки: permission/region/GPS ждут завершения
  первоначального восстановления заказа, даже если GPS ответит быстрее.
  После прибытия верхний статус больше не
  показывает устаревший расчёт пути к подаче. Эти последние правки
  прошли анализ/тесты/сборку, но ещё не повторный запуск на телефоне.
- После входа тем же водителем в web на телефоне поверх входа оказался
  runtime fallback; кнопка возврата восстановила вход. Выявлен сохранявшийся
  стек страниц старой сессии. `SessionNavigation` теперь сбрасывает страницы
  и диалоги при смене сессии/роли, но сохраняет их при смене темы/языка.
  Регрессионный widget test прошёл; повтор на телефоне нужен после установки.

Основные файлы: `passenger_shell.dart`, `passenger_map_viewport.dart`, новый
`passenger_startup.dart`, `trip_details_disclosure.dart`, ARB/генерируемые
локализации, `main.dart`, `session_navigation.dart` и четыре файла тестов Flutter.
Добавлены `physical-device-qa.js` и отдельная проверка его защитных ограничений.
Backend production-логика, миграции и state machine в этом сеансе не менялись.

### Показ через USB

Комплект локальный: компьютер с Docker и интернетом для внешних карт должен
работать во время показа. Это не автономный production APK.

1. Убедиться, что `http://127.0.0.1:4001/api/health/ready` на компьютере отвечает
   `env=development`, `status=ok`. Не менять production и не запускать seed там.
2. Подключить и разблокировать телефон с уже разрешённым ADB. Выполнить:

   ```powershell
   rtk proxy C:/Users/User/AppData/Local/Android/Sdk/platform-tools/adb.exe -s IBOVEMHQBQBQMJTS reverse tcp:4001 tcp:4001
   rtk proxy C:/Users/User/AppData/Local/Android/Sdk/platform-tools/adb.exe -s IBOVEMHQBQBQMJTS reverse tcp:5175 tcp:5175
   ```

3. Разрешить установку `SmartTaxi-review-USB.apk` на самом телефоне. Последняя
   попытка обновления вернула `INSTALL_FAILED_USER_RESTRICTED: Install canceled
   by user`; после этого повторных попыток/обходов не выполнялось. Данные
   приложения не очищались. Старое установленное приложение остаётся доступно.
4. После установки проверить повторный вход/восстановление активной поездки,
   GPS без перекрывающего диалога региона, статус прибытия, выход со страницы
   профиля при смене сессии и локальную web-ссылку.
   Автоматическое открытие браузера телефона инструментом было запрещено;
   ручное открытие `http://127.0.0.1:5175/order` остаётся непроверенным шагом.
5. Для web на компьютере открыть `http://127.0.0.1:5175/order` или `/driver`.
   Не открывать `web/index.html` через `file://`: приложению нужен HTTP server
   с SPA fallback. Проверенный способ — существующий Docker nginx.

Локальные seed-аккаунты: пассажир `+77000000001`, водитель `+77000000000`,
пароль обоих `123456`. Только development. Водитель и пассажир — разные
аккаунты. Повторный login того же водителя в CLI/web завершает его сессию
на телефоне: не запускайте эти проверки одновременно. Перед окончанием QA
водитель переведён offline, незавершённых поездок физического теста нет.

## Что остаётся перед публичным запуском

- **Подтверждение установки на телефоне** и повтор последних трёх Android-правок
  плюс USB-endpoint/share-link проверка на новом APK. Сборка не равна device QA.
- Дорожные испытания навигации, звук/TTS, фоновые GPS/уведомления и энергосбережение
  на целевых телефонах. Стационарные тесты этого не доказывают. В текущем локальном
  API Firebase Admin не настроен: socket/in-app уведомления проверены, push — нет.
- Согласование всего дизайна заказчиком: визуальная оценка субъективна; каждый
  экран на каждом размере/языке вручную не принят. Полноэкранный навигатор водителя
  использует raster FlutterMap, остальные карты — native/vector: полная parity
  карт не закрыта. Размер машины этого навигатора требует отдельного визуального
  прохода; native route line вслепую не переделывалась.
- Сейчас readiness использует внешний `router.project-osrm.org`, карта —
  OpenFreeMap/OSM, MapTiler не настроен. Перед нагрузкой нужен production routing/
  map deployment и проверенные условия провайдеров, не обещание SLA демо-сервиса.
  Трафик/пробки не проверены; вычисленный маршрут не является гарантией самого
  быстрого пути при текущем дорожном движении. Геометрия зданий не выдумывалась.
- Официальный региональный реестр `rka,label,lat,lng` + отдельный `meta.json`
  с checksum каждого региона. Pavlodar XLSX не импортирован.
- ИП/юридические решения, мерчант и его официальный API-контракт/webhook,
  Infobip sender ID, внешние лицензии/договоры, iOS/Mac/App Store, store accounts
  и подтверждения владельца. CARD выключен по умолчанию; фейковые оплаты в
  пользовательском показе не включались.
- Авторизованный production deployment с DNS/TLS, секретами, мониторингом,
  backup/restore и итоговым smoke в реальном окружении. Локальная репетиция
  восстановления уже описана в `local-recovery-rehearsal-2026-09-05.md`;
  она не доказывает наличие production backup. Публикация в stores не выполнялась.

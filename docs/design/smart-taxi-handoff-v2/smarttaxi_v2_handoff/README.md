Файл создан для того, чтобы другой ИИ, дизайнер или разработчик понял SmartTaxi без лишних вопросов.

## Файлы в архиве

1. `01_MASTER_PROMPT.md`
   Главный промпт для любого ИИ. Его кидай в ChatGPT / Claude / DeepSeek / Figma AI.

2. `02_FIGMA_DESIGN_PROMPT.md`
   Отдельный промпт для генерации дизайна в Figma/визуальном ИИ.

3. `03_DEVELOPER_PROMPT.md`
   Промпт для ИИ-разработчика, чтобы он сделал код приложения.

4. `04_UI_UX_SPEC.md`
   Спецификация UX/UI: что должно быть удобно, логично и почему.

5. `05_SCREENS_AND_FLOW.md`
   Полный список экранов и flow.

6. `06_DESIGN_TOKENS.json`
   Цвета, шрифты, радиусы, тени — можно отдавать разработчику.

7. `07_SHORT_PROMPT.txt`
   Короткий промпт, если нужно быстро объяснить задачу.

## Как использовать

Лучший порядок:

1. Сначала отправь ИИ файл `01_MASTER_PROMPT.md`.
2. Потом отправь `05_SCREENS_AND_FLOW.md`.
3. Если делаешь дизайн — добавь `02_FIGMA_DESIGN_PROMPT.md`.
4. Если делаешь код — добавь `03_DEVELOPER_PROMPT.md`.
5. Если ИИ путается — отправь `04_UI_UX_SPEC.md`.
6. Для цветов/стилей отправь `06_DESIGN_TOKENS.json`.

## Главная идея
SmartTaxi должен выглядеть как серьезный сервис такси: бело-золотой, чистый, дорогой, удобный, безопасный, понятный для клиента, водителя, оператора и админа.

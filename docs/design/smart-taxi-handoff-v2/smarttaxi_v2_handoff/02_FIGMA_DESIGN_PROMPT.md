# PROMPT FOR FIGMA / DESIGN AI

Create a complete premium UI/UX design system and app showcase for a taxi service called SmartTaxi.

Language: Russian.
Visual direction: warm white + gold premium taxi app.
Main colors:
- #F8F7F2 warm background
- #FFFFFF cards
- #F6B800 primary gold
- #FFD45C light gold
- #111827 text
- #6B7280 muted text
- #E8E0CB border
- #172026 dark sidebar
- #16A34A success
- #EF4444 danger

Create a large 16:9 showcase with many screens in one image and also separate editable frames.

Required mobile screens:
1. Login screen
2. Client registration
3. Driver registration
4. Passenger home with OpenStreetMap
5. Address selection
6. Tariff selection
7. Payment method selection
8. Driver search
9. Driver assigned
10. Passenger ride in progress
11. Ride completed
12. Rating screen
13. Client menu
14. Driver home
15. New order for driver
16. Driver ride screen
17. Driver balance
18. Driver history
19. Promo codes
20. Bonuses
21. Invite friend
22. Support chat
23. Notifications
24. OSM map full screen

Required web screens:
1. Admin dashboard
2. Users management
3. Drivers management
4. Trips management
5. Finance dashboard
6. Promo codes
7. Support dashboard
8. Operator ticket dashboard
9. Operator order details
10. Manual driver assignment

UX rules:
- One main action per screen.
- Gold buttons only for primary CTA.
- Secondary actions are white with border.
- Map is the main center of passenger and driver experience.
- Large readable typography.
- Soft shadows.
- Rounded cards.
- Clear hierarchy.
- Do not overload the UI.
- Do not mix client, driver, admin and operator features.
- Make it feel like a serious, trustworthy, premium taxi platform.

Important flows:
Client flow:
Login → signup → choose pickup/destination → choose tariff → choose payment → find driver → driver assigned → ride → payment/rating → history.

Driver flow:
Signup → document review → go online → receive order → accept/reject → navigate → complete trip → balance/history.

Operator flow:
Open tickets → review problem → chat → assign driver/refund/cancel/close.

Admin flow:
Dashboard → users/drivers/trips/finance/promos/support/settings.

Design style:
Premium, clean, soft, modern, fintech-like, not childish, not dark-heavy, not cluttered.

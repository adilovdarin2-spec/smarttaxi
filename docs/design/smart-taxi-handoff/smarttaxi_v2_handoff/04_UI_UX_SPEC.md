# SmartTaxi V2 — UI/UX Specification

## Product Positioning
SmartTaxi is a premium regional taxi platform with a clean white-gold interface. It must feel safe, fast, trustworthy and easy for both passengers and drivers.

## Key UX Promise
A user should understand every screen in 3 seconds and complete any main action in 1–2 taps.

## Passenger Main Experience
1. Open app.
2. Login/register.
3. See map.
4. Pickup is detected automatically.
5. User selects destination.
6. User sees price and tariffs.
7. User chooses payment.
8. User taps "Найти водителя".
9. App shows search progress.
10. Driver is assigned.
11. User sees car, rating, arrival time.
12. During ride user sees route, safety actions, chat/call.
13. After ride user rates and receives receipt.

## Driver Main Experience
1. Driver registers.
2. Uploads documents.
3. Waits for approval.
4. Goes online.
5. Receives order.
6. Sees price/distance/route.
7. Accepts or rejects.
8. Navigates to client.
9. Starts ride.
10. Completes ride.
11. Sees earnings.

## Operator Main Experience
Operator must solve problems fast:
- Search order by ID or phone.
- See ticket status.
- Open client/driver info.
- Open chat.
- Assign driver manually.
- Cancel or close issue.

## Admin Main Experience
Admin controls business:
- Today revenue.
- Active drivers.
- Trips count.
- Users count.
- Problem tickets.
- Financial statistics.
- Driver verification.
- Promo codes.
- City settings.

## UX Quality Checklist
- Main CTA visible without scrolling.
- Price visible before ordering.
- Driver details visible before ride.
- Cancel button exists during searching.
- Support available during active trip.
- Payment method visible before order.
- Trip status always visible.
- Admin table filters are visible.
- Operator tickets have priority/status.
- Driver can toggle online/offline quickly.

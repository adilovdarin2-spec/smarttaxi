# SmartTaxi Dark/Gold Final UI Handoff — 52 Screens

This package contains 52 dark luxury black/gold SmartTaxi UI reference screens and a Codex prompt for rebuilding the frontend UI.

## Use this package as source of truth

- Screens: `screens/`
- Prompt: `CODEX_SMARTTAXI_DARKGOLD_FULL_REBUILD_PROMPT.md`
- Manifest: `docs/screen_manifest.json`

## Important

- Service name is SmartTaxi.
- Logo is gold `S` inside shield/hexagon.
- Do not use TaxiApp, TaxiDriver, or unrelated logos.
- Admin/operator should be generated by Codex using this design system.
- Map API integration is deferred; use mock/OSM-style dark map placeholders.
